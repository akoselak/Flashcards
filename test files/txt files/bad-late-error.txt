Q: 'What is HTML?'
A: 'The structure of a web page.'
Q: 'What is CSS?'
A: 'The styling of a web page.'
Q: 'What is JavaScript?'
A: 'The behavior of a web page.'
Q: 'What is a browser?'
A: 'A program that displays web pages.'
Q: 'What is a server?'
A: 'A computer that sends pages to browsers.'
Q: 'What is a URL?'
A: 'The address of a web page.'
Q 'What is a loop?'
A: 'Code that repeats.'
